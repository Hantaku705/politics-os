# POLITICS OS

日本の現職国会議員711人の「約束（選挙公報の公約）」と「国会での行動（発言・法案・投票）」、政党本部のお金を、公式の記録だけで並べる静的Webサイトです。どの政党にも同じ計算を使い、計算方法・除外条件・変更の記録をサイトの「ルールと計算」タブで公開しています。

- サイト: https://politics-os.vercel.app/ （検索エンジンには載せていません）
- ルールと計算: https://politics-os.vercel.app/#rules
- AI・研究向け: [`llms.txt`](llms.txt) / [`catalog.json`](catalog.json)（全データの項目説明・出典・検算）

## 動かし方（概要）
- データはリポジトリに入っていません。Vercel のビルド（`build/fetch-data.mjs`）が非公開の GCS バケットから取得します（読み取り専用サービスアカウントの鍵を env `GCS_SA_KEY_B64` に設定）。
- 取得・組み立ては `pipeline/`（Python 3。`pypdf` など）。gcloud のアカウントは env `POS_GCS_ACCOUNT`（未設定ならアクティブなアカウント）。X の反応は env `XAI_API_KEY`、選挙公報の読み取りは Vertex AI（Gemini）を使います。費用がかかる取得は事前に見積もってください。
- 以下は開発の記録です。


ログインなしで制度・議員・政党・都道府県から公開記録をたどる静的Webアプリ。

## データ範囲

3人の公開記録をアプリの事例として同梱。2022年の質疑（塩川氏の公式サイト掲載）と2024年の参議院会議録・衆議院議案情報。2026年11月2日確認。2022年資料は独立した政府一次資料との突合を今後行う。

政党所属は記録の文脈。地域は金子氏の確認時の公式プロフィール（熊本4区）のみ。ほか2名の地域は未収録であり出生地からの補完なし。全議員名簿・集計母数は未収録。

順位・ROAS・GDP効果・期間あたり活動数は未算出。未確認を0と扱わない。政党の人数表の0は「このサンプルに該当する人物がない」の意味だけ。政党の政策全体を示さない。第216回参法2号は審査未了であり個人別反対票は存在すると仮定しない。

自動同期、オンライン投票、国会全体のランキングは未実装。ローカルストレージ、Cookie、分析タグ、外部フォントCDNは使わない。

## 3つの物差し（2026-11-04）
- ①公約の具体性（0〜100点）：本人の選挙公報の公約1こごとに 何を・どうする・いつまでに・どこまで を1点ずつ（4点満点）。平均÷4×100。公約3こ未満は点数なし。判定は `pipeline/score_pledges.py`（Gemini、原文の文字だけ）→ `pledges_spec.jsonl` → `build_records.py` が `pp.spec`／`pp.ck`。人の目視で50件中47件一致。
- ②進捗率（%）：準備中。公約ごとに 言った→動いた→通った→効いた。アクション率＝段階1以上÷公約数、実現率＝段階2以上÷公約数。
- ③努力（0〜100点）：直近1年に発言した会議の回数の百分位（政府側・議長・委員長を除く）。旧「行動の点数」。
- 合計点は出さない。法律になった数・質問主意書・お金の報告は「参考」の件数として表示。

## 議員の行動・結果・透明性・党公約（2026-11-02）
- 法案: 第211〜222回国会の議案一覧に載った議員提出法案・決議案等 422件（会期をまたいで継続した法案は会期ごとに別ページになるため、法案ごとに最新の1件へまとめた。2026-11-02修正、修正前は重複込み951件）。衆法は衆議院の議案情報から提出者・賛成者の全員名（`fetch_bills.py`）、参法は参議院の議案ページから筆頭発議者のみ（`fetch_san_bills.py`。共同発議者はPDFにしかなく未収録）。状態は「成立（公布あり）・可決・否決・一院で可決・未成立」。未成立は公式ページの最後の状態を併記し、否決とは扱わない。
- 参議院本会議の投票: 第211〜222回の577件のうち、押しボタン式投票で議員別の賛否が残る297件（`fetch_san_votes.py`）。全件で賛成・反対の合計が公式発表と一致。起立採決280件・PDFのみ6件は対象外。衆議院は個人の賛否を表示しない。
- 透明性: 総務省の関係政治団体一覧（640人）と令和6年分収支報告書（総務大臣届出分）へのリンク（`transparency.json`）。収支の金額は未読（スキャン画像のため）。旧文通費の使途報告は未公表、資産報告はオンライン非公開。
- 党公約: 15会派の直近国政選挙の公約から政治資金・透明性の項目のみ（`party_pledges.json`）。党の約束として政党ページに表示し、個人の公約とは混ぜない。
- 写真: Wikimedia Commons（`photos.json`、Wikidataで本人照合済み）を `photos/` に保存して自前配信（`fetch_photos.py`）。ライセンス・作者を議員の詳細に表示。
- 組み立て: `build.py` の後に `python3 -I pipeline/build_records.py "$W" "$W/data" "$W/photos"`。出力は members.json（件数）・records.json（詳細。議員の記録を開いたときだけ読み込む）・pledges.json。
- 検証: Playwright で議員カード・並び替え・参院／衆院議員の詳細・Escape・政党ページの公約・県別を 1440px／390px で確認（28項目合格、JavaScriptエラーなし）。

## 点数とランキング（2026-11-02）
- 議員カードと詳細に4軸の点数バー。行動＝発言件数と筆頭法案数の点数の平均、結果＝成立数の点数。点数＝現職のうち自分より値が小さい人の割合×100（最多100・最少0・0件は0点）。公約・透明性は判定基準がないため「未評価」。合計点は出さない。
- ランキングタブ：人物／政党（会派、院ごと、5人未満は参考）／県（小選挙区・選挙区＋衆院比例はブロックの全構成県、参院全国比例は含めない）。点数・法案は平均、発言件数は中央値。
- 計算はすべて app.js（`computeScores` / `rkGroups` / `rankRows`）で members.json から行う。データの再生成は不要。

## プロフィール詳細（2026-11-02）
- ランキングの行・議員カードの名前／写真を押すと詳細が開く。先頭に点数の内訳（もとの数字・点数・同率人数つきの順位・全議員と会派の中央値）。
- 国会での発言：`pipeline/fetch_speeches.py`（会議録API、4並列で約15分）→ `build_records.py` が `data/speeches.json` を作る。立場は会議録の肩書で「政府側の答弁／議長・副議長／それ以外」。委員長・提出者は肩書が付かないため「それ以外」。

## 点数の定義の改訂（2026-11-02、外部レビュー反映）
- 行動の点数＝発言のあった会議の回数（政府側・議長の発言を除く）の百分位。結果＝筆頭提出法律案の成立件数（件数表示・衆参同じ）。
- 委員会提出（委員長名義）・決議・規則は個人の法律案に数えず別表示。0の人は順位を出さない。
- 発言0件の議員は `pipeline/fetch_last_speech.py` で集計終了日以前の直近発言を表示。

## 参考サイトから取り入れた表示（2026-11-02）

## 類似サービスから取り入れた比較方法（2026-11-02）

- 質問主意書（`pipeline/fetch_questions.py`）、超党派の法律案、データ入手日と元記録リンクを全画面に。

## 本人の公約（選挙公報）と結果の拡張（2026-11-04）
- 公約: いまの議席を得た選挙（衆＝第51回2026年、参＝第27回2025年／第26回2022年）の選挙公報PDFを、各都道府県選管の公開ページから取得（`pipeline/config/kouhou_sources.json` → `pipeline/fetch_kouhou.py`）。PDFは手元に保存せず、メモリから直接 `gs://politics-os-data-2026/v1/raw/20261102/kouhou/` へ。
- 抽出: `pipeline/extract_pledges.py`。ページを200dpiで描画→Geminiで候補者の欄の位置を取得→現職の議員の欄だけを切り出して原文を50字以内で抜き出す（落選者の欄は読まない）。比例の公報は政党の欄なので使わない。
- 表示: 議員カードの公約欄「選挙公報の政策 N件（具体的・期限や数値あり）」、詳細に原文の一覧とPDFのページへのリンク。点数・率は出さない。見つからない議員には理由を表示（比例単独、公開終了の県、取得不可の県など）。
- 精度: 抜き取り11人・128件を公報の画像と照合し、125件一致（1文字の読み違い2件、途中を省いたもの1件）。公約と実績を分けて表示（AIの判定）。
- 結果: 筆頭・共同として加わった法律案の成立（重複なし）。参議院は共同発議者が公開資料に載っていないため筆頭のみ。
- 費用: Gemini（個人GCPプロジェクト）約6.3ドル（約950円）。

## 公費（2026-11-04）
- タブ「公費」: 衆議院の令和8年度予算（案）の主要5項目（秘書・歳費・調査研究広報滞在費・立法事務費・JRパス/航空）を465議席で割った平均（約8,111万円）。議員本人の年収ではない。
- 数字と出典は `pipeline/config/public_cost.json`、計算は `build_records.py` の `build_public_cost()`。参議院は制度が同じことだけを表示。
- 議員の詳細の透明性欄に、この議席の公費の目安と、調査研究広報滞在費の使途報告の状態（初回公開期限 2026-11-30）を表示。

## やさしい表示（2026-11-04）
- 対象: 政治に関心がない人・若い人。赤ポスターの見た目は残し、言葉を「です・ます」の短い文に。
- 政治用語は app.js の `TERMS` に説明を置き、`term('会派')` で点線の下線つきボタンにする（押すと吹き出し）。ページ下に「ことばの説明」。
- 議員カードは数字タイル4つ。注意書き・計算方法・出典は `<details class="more">`（くわしく）に入れ、消さない。
- 文字は最小13px。確認は scratchpad の `verify_easy.py`。
